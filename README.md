# 🚀 goit-node-rest-api (HW-04: REST API)

Цей проєкт реалізує **REST API** для роботи з колекцією контактів, використовуючи **Node.js** та фреймворк **Express.js**.

Він підтримує повний CRUD (Create, Read, Update, Delete) функціонал для управління контактами. Валідація вхідних даних здійснюється за допомогою бібліотеки **Joi**.

## 📋 Вимоги

- Node.js (рекомендована актуальна LTS-версія)

## 🛠️ Встановлення та запуск

Виконайте ці кроки для встановлення та запуску проєкту на вашій локальній машині.

### 1. Клонування репозиторію (або перехід до потрібної гілки)

```bash
# Якщо ви працюєте з гілки hw02-express
git checkout hw02-express
```

### 2\. Встановлення залежностей

Перейдіть до кореневої папки проєкту та встановіть необхідні модулі:

```bash
npm install
```

### 3\. Запуск сервера

Запустіть застосунок у режимі розробки:

```bash
npm start
```

Сервер запуститься на порту **3000**.
API буде доступний за адресою: `http://localhost:3000/api/contacts`

## 🔗 Ендпоінти API

Для тестування ендпоінтів рекомендується використовувати **Postman** або **VS Code Thunder Client**.

| Метод      | Шлях                | Опис                                                                                 |
| :--------- | :------------------ | :----------------------------------------------------------------------------------- |
| **GET**    | `/api/contacts`     | Отримати список усіх контактів.                                                      |
| **GET**    | `/api/contacts/:id` | Отримати один контакт за ID.                                                         |
| **POST**   | `/api/contacts`     | Створити новий контакт. **Body**: `{name, email, phone}` (обов'язкові).              |
| **PUT**    | `/api/contacts/:id` | Оновити існуючий контакт за ID. **Body**: `{name, email, phone}` (хоча б одне поле). |
| **DELETE** | `/api/contacts/:id` | Видалити контакт за ID.                                                              |

### Приклади JSON Body для POST

```json
{
  "name": "Dmytro Kovalenko",
  "email": "d.kovalenko@example.com",
  "phone": "(501) 123-4567"
}
```

```
└── package.json
```
